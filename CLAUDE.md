# Chinese writing rule

Read the adjacent `SKILL.md` before producing or reviewing Chinese.
Read it again after `/compact`, context restoration, a long-running task, task
switching, and before any commit, pull request, or review submission.

Apply it to chat, documentation, UI copy, alerts, logs, tests, comments, commit
messages, pull requests, and reviews. Read the active repository's instruction
files at the same checkpoints; more specific repository rules take precedence.
